```
P1001-A+B Problem.md
```

**题号 + 题目名**，一眼能搜到。

## 每份题解包含

1. 题目链接
2. 一句话思路
3. 关键步骤（为什么这么做）
4. 完整代码
5. 复杂度
6. 踩过的坑 ← **最重要，也是最容易忘的**

## 为什么建这个仓库

- 刷题有记录，不会刷完就忘
- 保研面试时能拿出「我刷了 179 题，每道都有题解」
- 回看自己踩过的坑，比重新想一遍快得多
