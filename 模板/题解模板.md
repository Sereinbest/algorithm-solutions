## P1001 A+B Problem

- **链接**：https://www.luogu.com.cn/problem/P1001
- **难度**：红
- **考点**：输入输出、整数运算

### 思路

一句话：读两个整数，输出它们的和。

C++ 的 `std::cin >>` 会自动跳过空白字符，所以不用手动处理换行和空格。

### 关键点

1. 变量要先声明再用，用 `long long` 防止大数溢出
2. `std::cin` 读取时遇到空格/换行就停，正好符合本题输入格式

### 代码

```cpp
#include <iostream>

int main()
{
    long long a{}, b{};
    std::cin >> a >> b;
    std::cout << a + b << '\n';
    return 0;
}
```

### 复杂度

- 时间：O(1)
- 空间：O(1)

### 踩过的坑

- 一开始用 `int` 存的，数据范围大的时候会溢出。**看到题先看数据范围**。
- `std::cout` 默认不换行，忘了 `'\n'` 就会被判格式错误（洛谷多数题不严格，但养成习惯）。
